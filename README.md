# AirPrint Bridge

Нативное приложение для macOS, которое превращает любой принтер, добавленный в систему, в AirPrint-устройство. iPhone и iPad видят его по Bonjour и печатают без драйверов и без покупки «AirPrint-совместимой» модели.

> Печать идёт через CUPS вашего Mac, поэтому Mac должен быть включён и находиться в той же сети, что и iPhone/iPad.

## Возможности

- Значок в строке меню: быстрое включение и выключение раздачи.
- Отдельный переключатель для каждого принтера, а также общий выключатель.
- Окно настроек: автозапуск при входе, автоматическая раздача новых принтеров, объявление цвета и дуплекса.
- Значок в строке меню можно скрыть. Настройки открываются повторным запуском из «Программ» или Launchpad.
- Список принтеров обновляется сам (раз в 30 секунд) и вручную кнопкой в окне.
- Сканеры никогда не раздаются автоматически.
- При запуске убираются «осиротевшие» Bonjour-объявления от прошлого сеанса.

## Требования

- macOS 13 Ventura или новее (проверено на macOS 15).
- Принтер, добавленный в «Системные настройки → Принтеры и сканеры».
- Для сборки: Command Line Tools (`xcode-select --install`).
- Если Xcode будет требовать лицензию, выполните команду  sudo xcodebuild -license accept 

## Установка из исходников

```bash
git clone <url-репозитория>
cd AirPrint/App
./build-app.sh --install     # собрать и установить в /Applications
./build-app.sh --dmg         # собрать установочный образ build/AirPrint-Bridge-<версия>.dmg
```

При первом включении принтера macOS один раз запросит пароль администратора: это нужно, чтобы включить общий доступ к очереди в CUPS.


## Как это работает

Приложение читает список очередей через `lpstat`, включает общий доступ в CUPS (`cupsctl`, `lpadmin`) и для каждого выбранного принтера запускает `dns-sd -R`. Он публикует сервис `_ipp._tcp,_universal` с AirPrint-записями (`URF`, `pdl`, `rp`, `Color`, `Duplex` и др.). iOS находит принтер в диалоге «Печать» и отправляет задание на IPP-порт 631 вашего Mac.

Исходники (SwiftUI, без внешних зависимостей) лежат в `App/Sources/AirPrintBridge/`:

| Файл | Назначение |
| --- | --- |
| `AirPrintBridgeApp.swift` | точка входа, меню в строке меню, окно настроек |
| `BridgeStore.swift` | состояние, настройки, управление процессами `dns-sd` |
| `CUPS.swift` | работа с CUPS: список очередей, общий доступ |
| `SettingsView.swift` | интерфейс настроек |

## Релиз для распространения

Ad-hoc подпись (по умолчанию) подходит только для вашего Mac. Для установки на другие компьютеры без предупреждений Gatekeeper нужен Apple Developer ID

## Диагностика

- Что объявлено в сети: `dns-sd -B _ipp._tcp,_universal`
- Запущенные объявления: `pgrep -fl "dns-sd -R"`
- Принтер виден дважды: проверьте, что включён «Общий доступ к принтерам» в системных настройках.

## Ограничения

- Параметры `URF` и `pdl` типовые. Для конкретной модели их можно уточнить в `BridgeStore.swift`.
- Если у принтера нет дуплекса, двусторонняя печать будет ручной.
- Приложение не подписано Developer ID, поэтому при первом запуске на другом Mac Gatekeeper покажет предупреждение.
